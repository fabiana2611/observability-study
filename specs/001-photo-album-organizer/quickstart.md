# Quickstart Guide: Photo Album Organizer

**Feature**: Photo Album Organizer | **Date**: 2026-01-06  
**Purpose**: Get the application running locally in 5 minutes

---

## Prerequisites

- **Node.js**: v18+ (check: `node --version`)
- **npm**: v9+ (check: `npm --version`)
- **Next.js 16.1.1, React 19.2.3, Tailwind CSS v4** (already in package.json)

---

## 1. Install Dependencies

```bash
cd /Users/fabiana.araujo/Development/studies/observability/observability-study
npm install better-sqlite3
```

**New package**:
- `better-sqlite3` - SQLite database for album/photo metadata

---

## 2. Initialize Database & Sample Data

```bash
npm run seed
```

**What this does**:
1. Creates SQLite database at `app/lib/database.db`
2. Creates tables (`albums`, `photos`)
3. Seeds 8 albums (cities) with 15 photos each (120 photos)
4. Downloads sample photos from Unsplash to `public/sample-photos/`

**Expected output**:
```
✓ Database initialized
✓ Created 8 albums
✓ Created 120 photos
✓ Downloaded 120 sample images
Database ready at: app/lib/database.db
```

---

## 3. Start Development Server

```bash
npm run dev
```

**What this does**:
1. Starts Next.js dev server on `http://localhost:3001`
2. Loads SQLite database via API routes
3. Serves sample photos from `public/` directory

**Expected output**:
```
> next dev
   ▲ Next.js 16.1.1
   - Local:        http://localhost:3001
   - Ready in 1.2s
```

---

## 4. Open Application

Visit **http://localhost:3001** in your browser.

**You should see**:
- 8 city album cards (Paris, Tokyo, New York, Barcelona, Sydney, Amsterdam, Rio, Dubai)
- Each album shows city name and photo preview
- Responsive grid layout

## 9. Troubleshooting

### Port 3001 already in use
```bash
# Find and kill process
lsof -ti:3001 | xargs kill -9
```

### Database errors
```bash
# Delete and recreate database
rm app/lib/database.db
npm run seed
```

### Missing sample photos
```bash
# Re-run seed script
npm run seed
```

### TypeScript errors
```bash
# Check types
npm run type-check
```

### localStorage not working
- Check browser privacy settings (allow localStorage)
- Try incognito/private mode
- Clear browser data and reload

## 10. Development Workflow

### Making Changes

**Frontend Components**:
1. Edit files in `app/components/` or pages in `app/`
2. Next.js hot-reloads automatically
3. Check browser console for errors

**API Routes**:
1. Edit files in `app/api/`
2. Save file - Next.js auto-restarts API routes
3. Check terminal for errors

**Database Schema**:
1. Edit `app/lib/db.ts`
2. Delete database: `rm app/lib/database.db`
3. Re-seed: `npm run seed`

### Testing Manually

**Mobile viewport**:
- Chrome DevTools: `Cmd+Opt+I` → Toggle device toolbar
- Test at: 375px, 768px, 1440px

**Touch events** (if no touch device):
- Chrome DevTools: Device mode → Select mobile device
- Simulates touch interactions
